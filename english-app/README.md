# えいかいわドリル（初心者向け英会話練習アプリ）

日本語の文が表示されるので、それを英語で答える練習アプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー・インストール不要）。

1. カテゴリ（あいさつ・自己紹介・日常会話・買い物・レストラン・旅行）と問題数を選ぶ
2. 表示された日本語を英語で入力（または 🎤 で声で答える）して「答え合わせ」
3. 結果と模範解答を確認し、🔊 で発音を聞いてまねして言ってみる

## 機能

- **ゆるやかな採点**: 大文字・小文字、句読点、短縮形（`I'm` = `I am` など）の違いは正解扱い。1つの文に複数の正解パターンを登録
- **単語ごとのフィードバック**: 合っている単語・余分な単語・足りない単語を色分けして表示
- **3段階ヒント**: 単語数 → 最初の単語 → 各単語の頭文字
- **発音の読み上げ**: 模範解答を少しゆっくり読み上げ（Web Speech API）
- **音声入力**: 🎤 で英語を話して回答（Chrome など SpeechRecognition 対応ブラウザのみ）
- **復習**: 間違えた問題の一覧と「間違えた問題だけ再挑戦」
- **学習記録**: 通算の正答数をブラウザに保存

## 問題の追加

`data.js` の `SENTENCES` に追加します。`answers` の最初の文が模範解答になります。

```js
{ cat: 'daily', ja: '雨が降っています。', answers: ["It's raining."] },
```

## テスト

```sh
node english-app/checker.test.js
```
